# X Intent Listener

A real-time social listening tool that helps discover public X posts from people actively looking for AI tools, automation, workflows, video creation, and developer help.

## Features

- Natural-language intent search
- Keyword-based search
- X API integration
- Relevance scoring
- Clean review feed
- Author, timestamp, engagement and post links
- Customizable search criteria
- Human-in-the-loop review
- No automatic outreach

## Example

Try searching:

> people looking for someone to create AI-generated videos

Or:

> developers asking for API integration help

The tool converts the request into relevant search terms and ranks matching posts.
